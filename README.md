# AGENT MANAGEMENT ENGINE

Tools for managing multiple agents on your system.

## Overview

Make new users, make a hypervisor to manage users/groups/secrets easily.

## Usage

`bash create-user.sh <agent-name>`

- Creates & configures new Linux user for the agent
- Sets permissions correctly, generates secrets
- Installs Hermes on system if needed.
- Sets up new Hermes profile for agent

## Features

- Create new agent user
- Install Hermes (system)

## Harness Support

Currently targets Hermes only, planned support for more later.
